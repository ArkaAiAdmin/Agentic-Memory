Invoked from one crontab line: `*/5 * * * * cd $REPO && python cron/scheduler.py`. CLI flags: `--dry-run` (list due commands without executing), `--list` (print all jobs with next-offset/due status), `--status` (24h summary from `cron_runs`), `--no-flock` (skip process-singleton lock, also via `MEMORY_CRON_NO_FLOCK=1`). DB path defaults to `MEMORY_DB_PATH` or the active memory dir's `memory.db`.
