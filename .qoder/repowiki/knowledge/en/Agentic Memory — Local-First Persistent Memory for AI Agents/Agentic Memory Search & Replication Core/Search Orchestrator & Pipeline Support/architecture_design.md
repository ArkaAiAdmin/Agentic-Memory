Single-process pipeline orchestrated by `search_memories` in `orchestrator.py`, which executes phases 1–14 sequentially (parse → skill-first lookup → cache → DB setup → FTS5+KG retrieval → embedding fallback → RRF fusion → temporal filter → chunk enhancement/session clustering → KG boost/multi-hop → cross-encoder + late-interaction + ColBERT + answer-rerank + LTR + temporal SSM → build items → safety/quality gates → finalize). Each phase is wrapped in try/except so failure increments an error counter and degrades gracefully rather than aborting.

Support modules are imported lazily inside the orchestration path to keep startup fast:
- `query_parser.py` — normalization, synonym/abbreviation expansion (`_QUERY_EXPANSIONS`, `_SYNONYM_MAP`, `_WORD_FORM_EXPANSIONS`), conceptual phrase expansion, query-type classification, zero-result suggestions.
- `scoring.py` — RRF fusion, six-channel weighted score (`bm25/fitness/importance/pinned/recency/tag_match`), CTR-driven weight tuning from `memory_ctr_feedback`, Ebbinghaus forgetting curve, strong-match float, TemporalAttentionModel SSM recency nudge.
- `config.py` — single pydantic `SearchConfig` view over `MemoryConfig`, cached per process with double-checked locking; mirrors legacy `_get_*` defaults exactly.
- `budget_aware.py` — per-call `SearchBudget` tracking elapsed vs `MEMORY_SEARCH_COMPUTE_BUDGET_MS`; stages call `budget.should_run(stage, estimated_cost_ms)` before running expensive rerankers.
- `enrichment.py` / `synthesis.py` / `drift.py` / `feedback.py` / `skill_lookup.py` — order-invariant post-rank enrichment (temporal decay, Jaccard surprise, concept/centrality boosts), optional synthesis summary, concept-drift event recording, CTR/memory-used feedback persistence, and early-skill match shortcut.

Dependency direction: `orchestrator.py` is the sole entry point; all other files are leaf utilities imported on demand. Shared mutable state (column cache, phase latencies, CTR weights cache, SSM model) uses module-level `threading.Lock`/`RLock` plus `threading.local()` for per-call latency dicts. The `ScoreContext` dataclass and `MemoryResultRow` NamedTuple define the internal row contract between phases.
