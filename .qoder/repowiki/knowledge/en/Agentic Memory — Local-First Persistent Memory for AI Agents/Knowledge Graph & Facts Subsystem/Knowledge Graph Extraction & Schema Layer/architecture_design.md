The package is a flat Python subpackage whose `__init__.py` re-exports the public surface (`graph_search`, `index_kg_for_memory`, `ensure_kg_schema`, …) so callers can still import from the legacy top-level module. Internal layering:
- `kg_schema.py` owns all DDL: `CREATE TABLE` statements for `kg_entities`, `kg_entity_aliases`, `kg_edges`, an FTS5 virtual table with INSERT/UPDATE/DELETE triggers, and the `kg_extraction_stats` stats table; `ensure_kg_schema(conn)` also runs `PRAGMA table_info` to backfill missing columns on existing DBs.
- `kg_extract.py` implements the extraction pipeline: content cleaning (frontmatter/code-block stripping), pattern-based NER over five extractor functions (capitalized phrases, org/place/date patterns, curated `_CONCEPT_KEYWORDS`, email/url), stop-word and file-path filtering, frequency gating, and a bounded LRU in-memory cache keyed by `sha256(content)[:16]`. Relation extraction falls back to sentence co-occurrence of entity pairs when LLM relation extraction is unavailable.
- `kg_db.py` holds the persistence layer: `_upsert_entity` resolves duplicates through fingerprint → exact name/alias → Jaccard fuzzy match (≥0.85 similarity adds an alias); `_upsert_edge` increments weight up to a configurable cap or inserts a new edge guarded by a partial unique index on `(source_id, target_id, relation) WHERE invalid_at IS NULL`; `invalidate_edge` soft-deletes edges to enable temporal versioning; `index_kg_for_memory` orchestrates the two-stage extraction (regex then LLM fallback) and writes per-memory rows into `kg_extraction_stats`.
- `ner_spacy.py` is an optional augmentation gated by config; it loads `en_core_web_trf` and appends PERSON/ORG/GPE/PRODUCT/FAC entities not already present in the regex result set.
Dependency direction is one-way: `kg_db.py` imports helpers from `kg_extract.py`; `kg_schema.py` has no runtime dependencies beyond `sqlite3`; `ner_spacy.py` is imported lazily only when enabled. The package depends on external modules `infra.db.AnyConnection`, `infra._lazy_imports.get_config`, `llm_extraction`, and `kg.kg_crdt` (for fingerprint computation and entity redirect resolution).
