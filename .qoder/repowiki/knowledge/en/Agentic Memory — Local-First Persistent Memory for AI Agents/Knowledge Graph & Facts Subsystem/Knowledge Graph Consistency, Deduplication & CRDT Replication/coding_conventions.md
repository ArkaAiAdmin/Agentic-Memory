- Optional external dependencies (config, embedding search, LLM provider, db pool) are imported lazily inside try/except blocks at module top or function entry, falling back to defaults or returning empty results rather than failing hard.
- Database mutations wrap their work in explicit `BEGIN IMMEDIATE` / `commit` / `rollback` blocks, checking `getattr(conn, 'in_transaction', False)` so they are safe when called from callers already holding a session transaction.
- CRDT operations are immutable: every version-vector mutation returns a new dict, and merge functions (`merge_entity_ops`, `merge_edge_ops`) take iterables and produce new result dicts without touching the DB, keeping pure logic separate from persistence helpers like `apply_*_to_db`.
- Edge endpoints are always canonicalised through `resolve_edge_endpoints` / `resolve_entity_id` before any `INSERT INTO kg_edges`, making the no-orphan invariant a write-time guarantee rather than a post-hoc cleanup task.
- Dedup and projection functions return structured stats dicts with uniform keys (`entities_merged`, `edges_redirected`, `groups_found`, `dry_run`) so callers can print consistent summaries regardless of exact vs semantic path.
