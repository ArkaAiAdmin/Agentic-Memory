The module is organized as a set of independent encoder/store backends plus a top-level orchestrator:

- `vector_store.py` defines the `VectorStore` Protocol and two concrete implementations — `USearchVectorStore` (default, uses `usearch.index.Index`) and `NumpyVectorStore` (pure-Python brute-force cosine/L2/inner-product). A `get_vector_store()` factory selects the backend by string; `from_blob()` deserializes. This protocol is the boundary that `embedding_search.py` depends on.
- `embedding_search.py` is the main entry point: `EmbeddingSearch` lazily loads one of three embedding backends (`model2vec`, `sentence-transformers`, or raw `transformers` mean-pooling) based on config/env, caches query embeddings in an LRU, persists per-memory dense vectors into `memory_embeddings`, and drives a two-stage search path — ANN via a persisted usearch index (`_load_vec_index` + `_search_via_index`) with FP32 rerank over candidates, falling back to a full-scan when the index is missing/stale. It also maintains a process-local usearch-index cache keyed by db_path and invalidates it on `built_at`/blob-length/model_id drift.
- `splade_encoder.py` and `colbert_encoder.py` are optional late-interaction/sparse encoders built on `transformers`; both lazy-load their models under a lock, fall back gracefully (SPLADE has a deterministic MD5-hash fallback when the model is unavailable), and expose `encode_*` functions returning per-token or sparse `(vocab_id, weight)` pairs.
- `reranker.py` provides an opt-in deep cross-encoder (`Qwen/Qwen3-Reranker-0.6B` primary, `BAAI/bge-reranker-v2-m3` fallback) behind a singleton `Reranker`, with MPS-hung-kernel protection via a persistent child-process worker pool (`_MpsWorkerPool`).
- `embedding_recompute.py` is a CLI wrapper that compares the current embedding model config against stored vec-index metadata and re-invokes `rebuild_vec_index.py` when they diverge.
- `fts.py` holds SQLite FTS5 schema/triggers and orphan-cleanup helpers extracted from `memory_common.py`.

Dependency direction is one-way: `embedding_search.py` → `vector_store.py` + `reranker.py` + `splade_encoder.py` + `colbert_encoder.py`; the encoders and reranker do not import each other. All heavy third-party imports (`torch`, `transformers`, `usearch`, `model2vec`, `sentence_transformers`) are deferred inside methods so the module can be imported without those packages installed.
