`embedding_search.py` documents running via the venv python (`~/.config/agentic-memory/venv/bin/python embedding_search.py <query>`). `embedding_recompute.py` accepts `--force` and `--dry-run` flags and auto-invokes `rebuild_vec_index.py` when the embedded model's id/dimensions change; it locates the venv by walking `install_root()/venv`, then `.venv`, then falls back to `sys.executable`.
