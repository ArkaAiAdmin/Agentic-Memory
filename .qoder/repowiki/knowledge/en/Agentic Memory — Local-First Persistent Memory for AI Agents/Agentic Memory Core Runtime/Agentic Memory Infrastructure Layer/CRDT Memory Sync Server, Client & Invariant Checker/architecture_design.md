Three cooperating layers inside a single package:
- Server (`sync_server.py`): a threaded `http.server.HTTPServer` with a custom `_SyncHandler` exposing `/health`, `/crdt/changes`, `/crdt/push`, plus parallel KG/skills/agents CRDT routes. Each request opens a per-request SQLite connection via `_open_server_db` (which uses the project's write-queue session or falls back to a flock-guarded raw connection) and applies tenant scoping on every query. Auth is enforced through `_require_auth` (Bearer token from `MEMORY_SYNC_TOKEN` / `MEMORY_API_TOKEN`, loopback bypass), replay protection via `X-Sync-Timestamp`, HMAC body signing via `X-Sync-Signature`, CORS allowlist via `MEMORY_SYNC_CORS_ORIGINS`, and max-body-size guard.
- Client (`sync_client.py`): stateless HTTP client using stdlib `urllib.request` with exponential-backoff retry (`_do_request`) over transient errors; exposes `pull_from_peer`, `push_to_peer`, `sync_with_peer`, and the CLI entrypoint `sync_once` which auto-discovers peers via `infra.pex_protocol.peer_directory`. Push/pull results are persisted in the local `sync_log` table for delta tracking.
- Daemon (`sync_server_daemon.py`): thin process bootstrap that parses `--host/--port/--db-path`, optionally sets `setproctitle`, initializes agent context, installs SIGTERM/SIGINT handlers calling `server.stop()`, and runs `SyncServer.start()` in the foreground.
- Invariants (`sync_invariant.py` + `sync_check.py`): read-only diagnostics that compare row counts across `memories`, FTS, embeddings, vector index, KG entities/edges/facts, chunks, tiers, metadata, and adaptive retention, flagging "drift" when coverage drops below configurable thresholds and detecting reverse ghosts pointing at soft-deleted memories; `sync_check.py` is the executable CLI wrapper.

Dependency direction: server → `crdt.crdt_merge`, `crdt.crdt_field`, `kg.kg_crdt`, `infra.db_*`, `infra.config_drift_policy`; client → `crdt.crdt_merge`, `crdt.crdt_field`, `infra.db`, `infra.pex_protocol`; daemon → server only; invariant checker → `infra.memory_common` + `infra.sync_invariant`.
