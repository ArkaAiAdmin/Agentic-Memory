Four independent leaf utilities wired together by the process entry point rather than sharing a package-level interface:
- `api_server.py` — self-contained HTTP stack built on `http.server.ThreadingHTTPServer` + `BaseHTTPRequestHandler`. It implements its own router (`do_GET/POST/PUT/DELETE` dispatch chains), JSON I/O, CORS, an in-process sliding-window rate limiter keyed by principal ID or client IP, and two-phase auth (Authlib JWT via `infra.authlib_sso` with static bearer-token fallback). WebSocket upgrades at `/ws` and `/api/v1/streaming` use the Outbox pattern to stream events. All business calls go through `agentic_memory.client.MemoryClient` or direct DB access via `infra._lazy_imports.connection_pool`, keeping this layer thin.
- `mdns_discovery.py` — pure-Python mDNS over UDP multicast (`224.0.0.251:5353`) implementing `MDNSAdvertiser` (PTR/SRV/TXT/A response loop) and `MDNSBrowser` (periodic PTR query + response parser) for local peer sync-server discovery; no external dependency.
- `mcp_singleton.py` — per-agent file-lock guard using `flock` via `infra.file_lock.acquire_flock_with_retry`; lock path is `.mcp_server.lock.<MEMORY_AGENT_ID>` under the active memory directory, with stale-PID override and `atexit` release.
- `toml_watch.py` — single-source-of-truth mtime tracker for `memory.toml` exposing `current_mtime()` / `refresh_mtime()` / `subscribe()`. A lazily started daemon thread polls every `_POLL_DEFAULT=1.0`s, debounces via `_DEBOUNCE=0.05`, and when `MEMORY_TOML_HOT_RELOAD` is set fires `apply_hot_reload()` which re-applies drift-tier overrides then resets the policy cache.

Dependency direction is one-way outward: this module depends on `agentic_memory.client`, `infra.authorizer`, `infra.authlib_sso`, `infra.audit`, `infra.config*`, `save.pipeline`, and `infra.file_lock`; nothing inside imports from sibling infra modules except these well-known anchors.
