Environment variables control behaviour at runtime: `MEMORY_DB_POOL_SIZE` (default 24), `MEMORY_SQLITE_MMAP_SIZE` (default 256 MiB), `MEMORY_DB_FLOCK` (1=on, 0=off), `MEMORY_WRITE_QUEUE_IDLE_S` (session idle timeout), `MEMORY_WRITE_QUEUE_RESP_TIMEOUT_S`, `MEMORY_JOURNAL_STUCK_AGE`, `MEMORY_JOURNAL_MAX_RETRIES`, `MEMORY_JOURNAL_MAX_SIZE_BYTES` (50 MB), `MEMORY_CRON_TENANT_ID` / `MEMORY_TENANT_ID` (tenant routing for the write queue's tenant view).
