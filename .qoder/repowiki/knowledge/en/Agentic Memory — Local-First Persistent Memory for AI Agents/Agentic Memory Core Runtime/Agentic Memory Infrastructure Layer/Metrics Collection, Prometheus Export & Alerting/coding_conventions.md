- Global mutable state is exposed through a lazy-initialized module-level singleton accessed via a `get_*()` accessor guarded by a threading lock (see `_runtime`, `ErrorCounter._global_counter`, `AlertConfig._config`).
- All shared state mutations are wrapped in `with self._lock:` blocks around `threading.Lock()` instances, making every counter/histogram/error-entry update thread-safe.
- Rolling windows are bounded by truncating lists to a fixed tail slice (latency list capped at 1000 entries, error entries capped at `max_entries`) rather than using external libraries.
- Prometheus metrics follow the standard `# HELP` / `# TYPE` header lines followed by `metric_name{label="value"} number` exposition format, generated by string formatting instead of a library.
- External I/O (HTTP POST to Slack/Pushover, SMTP send, DB queries) is wrapped in try/except that logs the failure and continues processing remaining channels rather than raising.
