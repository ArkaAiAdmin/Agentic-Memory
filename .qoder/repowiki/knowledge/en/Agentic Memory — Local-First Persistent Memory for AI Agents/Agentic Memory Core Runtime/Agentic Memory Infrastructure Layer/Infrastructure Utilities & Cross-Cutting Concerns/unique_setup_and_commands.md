`pinned_decay.py` is executable as a CLI script (`python pinned_decay.py [--dry-run] [--json] [--auto-apply]`) and exits with code 0 (nothing to do), 1 (candidates found in dry-run), or 2 (auto-decay applied). Configuration is loaded from `memory.toml` next to this package or `~/.config/agentic-memory/memory.toml`, overridable via `MEMORY_CONFIG_PATH` and individual `MEMORY_*` env vars. The saga write path is gated by `MEMORY_SAGA_ENABLED` (default ON) and integrity-critical flags trigger stderr warnings when disabled.
