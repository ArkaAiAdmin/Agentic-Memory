Two-layer runtime with a strict harness-agnostic boundary:

- `plugin/` (TypeScript) is the only OpenCode-facing surface. `index.ts` implements the `@opencode-ai/plugin` contract, maps event names (`tool.execute.before`, `session.created`, `experimental.chat.system.transform`, …) to handler functions via `HANDLER_MAP`, and exposes a `HarnessAdapter` (log / spawn / fireAndForget / injectIntoSystemPrompt / getState). The adapter resolves the Python venv under `<AGENTIC_MEMORY_DIR>/venv|/.venv/bin/python` and spawns each hook as a separate process.
- `agentic-memory-hooks.ts` holds pure hook logic (startSession, onToolAfter, beforeTool, endSession, injectSystemPrompt, onCompacting). It orchestrates child-process calls into the sibling Python scripts under `hooks/` (`memory-session-start.py`, `memory-recall-session.py`, `memory-proactive-context.py`, `memory-coordination.py`, `memory-precompact-snapshot.py`, `memory-session-end.py`) plus `context_monitor.py` and `auto_save.py`. A per-label in-process circuit breaker (threshold 4, 5 min cool-down) plus a file-backed sentinel (`memory/.auto_save_circuit_sentinel`) guard against cascading failures; errors are appended to `memory/hook-errors.jsonl` and surfaced on the next call.
- Each Python hook is an independent CLI: reads JSON from stdin, writes structured text to stdout for the TS layer to inject into the system prompt, and uses `sys.path.insert(0, parent)` + `_bootstrap_path.INSTALL_ROOT` to import shared modules (`infra._bootstrap_path`, `search.orchestrator`, `session_manager`, `coordination.*`). Hooks share a per-process dedup cache keyed by query string and a disk-backed `hook_cache.json` TTL'd on DB mtime.
- `reasoning/compile.py` provides three background knowledge-compilation tasks (entailment-chain inference, concept compilation to `concepts/<slug>.md`, procedural-to-declarative enrichment into `principles/` or `ontology/`) exposed via `handle_*` entry points consumed by `background_worker.py`; it writes Markdown artifacts alongside the SQLite memory DB and persists provenance in `entailment_chains`.
- `skills/` contains human-readable SKILL.md files documenting how to extend the plugin (add hooks, cron jobs, MCP tools, memory architecture); they are not code but serve as authoring guides.
