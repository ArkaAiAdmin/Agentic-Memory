Two of the three files are thin compatibility shims: `consolidate_facts.py` forwards every attribute access to `fact.consolidate_facts`, and `kg_dedup.py` forwards to `kg.kg_dedup`; both also install an `infra._shim.install_shim` entry so the old import path behaves like a normal package. The third file, `consolidation.py`, is the actual implementation — it performs LLM-free duplicate detection (exact SHA-256 on normalized text plus Jaccard similarity over token sets) and tag-based clustering against the SQLite-backed `memories` table, exposing `detect_duplicates`, `cluster_related`, `merge_suggestions`, and `consolidation_stats`. It gates itself behind a `CONSOLIDATION_ENABLED` flag resolved lazily via `make_lazy_getattr` from `infra.memory_common` so the dependency on `infra.db.AnyConnection` is only imported under `TYPE_CHECKING`. Dependency direction is one-way: this leaf depends on `infra.*` and on sibling packages `fact` / `kg`, but nothing here imports back into them.
