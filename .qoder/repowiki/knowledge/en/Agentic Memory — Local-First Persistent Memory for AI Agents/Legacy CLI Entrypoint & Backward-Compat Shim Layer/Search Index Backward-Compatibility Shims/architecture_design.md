Each file is a one-line redirect: it imports the canonical implementation from `infra.*` and exposes it via `__getattr__` / `__dir__` so old code importing `embedding_search`, `fts`, or `embedding_recompute` continues to work. `embedding_recompute.py` additionally replaces its own module class with `_ShimModule`, which proxies attribute access (including `__setattr__`/`__delattr__`) through a lazily bound `_real` reference, allowing callers to mutate imported symbols after import time — unlike the simpler read-only shims in `embedding_search.py` and `fts.py`. The shim registry is wired via `infra._shim.install_shim` when the module is loaded as `__main__`.
