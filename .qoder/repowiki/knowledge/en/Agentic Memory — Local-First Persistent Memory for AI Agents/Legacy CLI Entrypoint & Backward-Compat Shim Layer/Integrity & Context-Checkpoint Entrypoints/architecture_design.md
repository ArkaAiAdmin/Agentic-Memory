Three leaf files form a thin compatibility / orchestration layer over deeper packages:
- `contradiction_detector.py` and `eval_judge.py` are pure re-export shims (`__getattr__` + `install_shim` in the former; star-import from `kg.contradiction_detector` and `eval.eval_judge`) so older import paths keep working.
- `context_monitor.py` is the real workhorse. It exposes OpenCode hook entry points (`track_tool_call`, `session_idle`, `session_end`, `pre_compaction`, `get_status`) that mutate a persistent JSON state file under `$AGENTIC_MEMORY_DIR/sessions/.context_monitor_state.json`. State writes use an exclusive `fcntl.flock` on a sibling `.flock` file plus `infra.memory_common.atomic_write` to avoid clobbering between concurrent short-lived subprocesses (OpenCode hooks). On each tool call it increments counters, records up to 100 notable tools with type-aware previews, and triggers a checkpoint every `CHECKPOINT_INTERVAL=10` calls. `pre_compaction` deduplicates via a 45s window, reads auto-save notes from `auto-YYYY-MM-DD_*.md` files, synthesizes four structured sections (conclusions/insights/todos/next_steps) from tool activity, writes a `sessions/compaction-save-*.md` note to disk, pins it in the memory DB via `save_memory_auto`, then enforces pin limits and retention by scanning both the DB and filesystem for orphaned compaction artifacts. All heavy imports (`infra._lazy_imports.save_memory_auto`, `infra.memory_common`, `session_manager.SessionManager`) are lazy-loaded inside functions to keep startup fast.
