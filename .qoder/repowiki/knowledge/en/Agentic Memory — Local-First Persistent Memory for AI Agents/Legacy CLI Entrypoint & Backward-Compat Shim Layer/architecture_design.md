Every file in this scope is a thin backward-compatibility wrapper: it imports the real implementation from its new home (infra.*, fact.*, kg.*, embedding_search, etc.) and re-exports it so legacy top-level imports resolve. The only non-shim files are `cli.py` (the MCP server + Streamlit dashboard bootstrap) and `llm_providers.py` (the provider registry), which act as the single runtime boundary where shims converge on their real targets. This layer has no logic of its own — it exists solely to preserve import contracts across package migrations.
