`python cli.py init` bootstraps the project by running `setup_memory.sh` inside `AGENTIC_MEMORY_DIR=~/.config/agentic-memory`; `python cli.py install-mcp` auto-writes MCP server entries into OpenCode (`~/.opencode/mcp-configs/mcp-servers.json`), Claude Desktop, and Claude Code configs. The dashboard is launched as a child process via `streamlit run dashboard.py --server.port/--server.address/--server.headless` and its lifetime is tracked in `~/.config/agentic-memory/memory/.dashboard.pid`.
