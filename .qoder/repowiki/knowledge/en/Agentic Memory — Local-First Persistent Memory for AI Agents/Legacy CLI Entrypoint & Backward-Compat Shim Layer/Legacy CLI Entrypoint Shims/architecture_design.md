Each file (`config.py`, `infrastructure.py`, `frontmatter.py`) is a thin compatibility layer: it imports the canonical implementation from `infra.config`, `infra.infrastructure`, and `infra.frontmatter` respectively, then exposes them via module-level `__getattr__`/`__dir__` forwarding. On import (when `__name__ in sys.modules`), each shim replaces its own class with a custom `_ShimModule(types.ModuleType)` subclass so that attribute assignment/deletion also forwards to the underlying `infra.*` module while protecting the internal `_real` handle. This lets legacy code that `import config` / `import infrastructure` / `import frontmatter` continue working without modification while the authoritative source of truth lives under the `infra/` package.
