Each file is a thin compatibility layer: it imports the corresponding `infra.<name>` module as `_real` and replaces its own module object's class with a custom `_ShimModule(types.ModuleType)` whose `__getattr__`/`__setattr__`/`__delattr__`/`__dir__` forward all attribute access to `_real`. The shim is installed into `sys.modules[__name__]` at import time so callers importing `cli_entrypoints.concurrency_primitives.cache` (etc.) transparently hit the real implementation in `infra.cache`, `infra.dist_lock`, and `infra.file_lock`. There is no logic of its own — dependency direction is strictly one-way toward `infra.*`.
