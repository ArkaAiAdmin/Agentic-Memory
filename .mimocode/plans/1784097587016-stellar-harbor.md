# Fix: Surface Feature Flags Error in Health Tab

## Problem
The Health tab's "Feature Flags" section shows "Could not load feature flags" because the `except Exception:` block at line 2717 swallows the real error with no details.

## Root Cause
The `except Exception:` block in `dashboard.py:2717` catches every exception but only shows a static uninformative message. The actual error (likely from `get_config()`, `cfg.features`, `cfg.search`, or attribute access) is invisible.

## Fix
1. Change `except Exception:` to `except Exception as e:` and log/show the actual error
2. This will surface the real exception on the dashboard for debugging

## File
- `dashboard.py:2717` — change from `except Exception:` to `except Exception as e:` with error display

## Verification
- Restart dashboard
- Check Health tab → Feature Flags section
- Should show actual error message instead of "Could not load feature flags"
