Run the full isolated suite: `python3 eval/run_full_suite.py`. Individual benchmarks are invoked directly, e.g. `python3 eval/real_memory_eval.py`, `python3 eval/locomo_eval.py --max-questions 50`, `python3 eval/adversarial_memory_eval.py`, `python3 eval/run_longmemeval_s.py`. Embedding-backed tests require `MEMORY_TEST_EMBEDDING=1` before import so the small model loads early. The suite defaults `MEMORY_AUTH_MODE=open` in `conftest.py`; security tests must explicitly set `MEMORY_AUTH_MODE=closed` via the `closed_auth_env` fixture.
