The package is the pip-installable surface of agentic-memory. Top-level `__init__.py` re-exports the public API (`MemoryClient`, `AgentMemory`, `KnowledgeGraph`, `TemporalKG`, `Maintenance`, `Admin`, `SyncManager`) plus a CLI entry point `main()` wired to `python -m agentic_memory`. `client.MemoryClient` is the core facade: it owns a resolved `db_path`, performs direct SQLite queries via `agentic_memory.utils` helpers (`get_db_connection`, `safe_close_db`), and delegates heavy operations (save/search/rebuild/quality/retention) to external modules imported lazily at call time (`infra._lazy_imports.save_memory_auto`, `memory_delete`, `mcp_kg`, `mcp_audit`, `mcp_quality`, `mcp_retention`, `mcp_summarization`). Domain sub-clients (`kg`, `temporal`, `admin`) are exposed as lazy properties so they are only instantiated on first use. `agent.AgentMemory` wraps `MemoryClient` by pushing an agent context via `agent_context.init_agent` / `temporary_agent_context`, scoping all writes/reads to a namespace prefix. `models.py` defines the typed dataclass return shapes; `exceptions.py` defines the error hierarchy. The `integrations/` sub-package provides optional framework adapters — LangChain (`retriever`, `history`, `tool`, `callback`) and CrewAI (`memory`, `tool`) — each guarded by try/except ImportError so the core package installs without them, and the top-level `integrations/__init__.py` exposes lazy loaders returning `None` when extras are missing.
