Three sibling artifact directories each bundle one paper's Markdown source, PDF, Makefile, and a self-contained Python package:
- `paper_pipeline/` — Paper 1 (Conflict-Free Knowledge Graph Projection). Core logic in `crdt_projection.py` (three-phase pipeline: `merge_entity_ops` → `entity_dedup_via_crdt` → `redirect_edge_ids`, plus `compute_fingerprint` and version-vector helpers) with `ck_crdt.py` as an alternate CK-CRDT variant; tests in `test_pipeline.py` (51 unit tests) and `test_adversarial.py` (37 adversarial/convergence tests); `benchmark.py` drives evaluation figures.
- `paper_pipeline_2/` — Paper 2 (Content-Keyed CRDT Framework). Mirrors the same layout but emphasizes the K1–K3 theoretical framework in `ck_crdt.py`; `test_adversarial.py` contains the formal counterexample suite (`TestK1Necessity`, `TestK2Necessity`, `TestK3Necessity`) verifying Theorem 1 and Lemmas 1–2.
- `paper_pipeline_3/` — Minimal companion for the third paper, containing only the Markdown/PDF build via pandoc + xelatex.

Each directory is independent (no cross-imports between siblings), uses only the Python standard library (`sqlite3`, `dataclasses`, `hashlib`, `json`, `unicodedata`, `typing`), and ships double-blind anonymized zips generated by the Makefile targets `artifact-double-blind`. The READMEs document alignment points back to the production implementation in `kg/kg_crdt.py` of the upstream agentic-memory repo.
