Each file in this scope is a pure forwarding shim with no logic of its own. `kg_crdt.py` uses a module-level `__getattr__`/`__dir__` plus an `infra._shim.install_shim` call to proxy attribute access onto `kg.kg_crdt`. `crdt_field.py` and `crdt_merge.py` follow the same pattern but additionally replace their own module class at runtime with a `_ShimModule` (a custom `types.ModuleType`) whose `__setattr__`/`__delattr__` forward mutations to the underlying `_real` module, ensuring even imported references see live updates. Dependency direction is strictly one-way: these files depend on the canonical implementations under `kg/` and `crdt/`, never the reverse.
