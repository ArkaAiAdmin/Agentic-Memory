- `kg_traversal.py` and `fact_extraction.py` are pure re-export shims: they import the canonical implementations from `kg.kg_traversal` and `fact` respectively and forward all attribute access via `__getattr__`, with `infra._shim.install_shim` registered when loaded as a module so callers see the same module identity.
- `cross_session_learn.py` is an independent executable (`#!/usr/bin/env python3`) that walks `sessions/*.md` files in the active memory directory (resolved via `infra.infrastructure.resolve_active_memory_dir`), applies keyword-based pattern signals (`PATTERN_SIGNALS`) against a minimum length threshold, deduplicates against existing `lessons` rows in SQLite, and writes new lesson notes through `save_pipeline.upsert_row` followed by the full save-pipeline indexing chain (`_index_chunks`, `_index_embedding`, `_index_kg`, `_index_facts`, backlink indexers, adaptive retention).
- Dependency direction is one-way: this leaf depends on `infra.*`, `save_pipeline`, `skill_extractor`, and `save.indexers`; it does not expose any public API beyond its own CLI entrypoint.
