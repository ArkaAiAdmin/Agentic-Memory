Each file is a one-line redirect: it imports the canonical module under `infra.*` and exposes its public API via `__getattr__`/`__dir__` so old code importing `cli_entrypoints.persistence_layer.db*` continues to work. `db.py` uses a simple function-based proxy plus an `install_shim` helper from `infra._shim`, while `db_migrations.py` and `db_path_flock.py` go further by replacing the module's class with a custom `_ShimModule(types.ModuleType)` that also forwards attribute assignment/deletion to the underlying `infra.*` module (with `_real` protected). The dependency direction is strictly outward — these files depend on `infra.*` and expose no logic of their own.
