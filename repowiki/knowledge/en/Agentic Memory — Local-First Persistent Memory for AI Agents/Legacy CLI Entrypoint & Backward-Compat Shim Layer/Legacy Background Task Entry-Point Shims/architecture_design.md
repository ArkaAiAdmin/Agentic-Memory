Each file is a thin compatibility shim: it dynamically imports the canonical implementation (`background.background_queue`, `background.background_worker`, `infra.db_write_queue`), then replaces its own module class with `_ShimModule`, which forwards all attribute access, mutation, deletion, and introspection to the underlying `_real` module. `background_worker.py` additionally exposes a `__main__` entry point that delegates to `_real.main()`. The shims also inject a sibling `cron/` directory into `sys.path` when run as a script so legacy relative imports inside the old package layout continue to resolve. There is no logic of its own — dependency direction is strictly outward toward the relocated `background/` and `infra/` packages.
