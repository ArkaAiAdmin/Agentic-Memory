Scripts are not imported as a package — they must be executed directly from the repository root so the `sys.path` hack can locate sibling modules. Many accept `MEMORY_DB_PATH` env var to override the target database. `cron_backup.py --install-cron` installs a daily-at-2am entry tagged with `# agentic-memory-backup`; `cron_cleanup_auto_logs.py` supports `--dry-run` and `--max-age-days N` flags.
