The site is a flat collection of Markdown pages under `docs/` consumed by Material for MkDocs (configured at repo root `mkdocs.yml`). Content is partitioned by Diataxis genre — `concepts/`, `how-to/`, `reference/`, `explanation/`, plus cross-cutting folders `api/`, `architecture/`, `benchmarks/`, `compliance/`, `guides/`, `integrations/`, `security/`, and `templates/`. A single Python build hook at `_hooks/copy_docker_readme.py` registers `on_pre_build`/`on_post_build` callbacks to symlink `docker/README.md` into `docs/docker_README.md` during builds and clean it up afterward. Authoring templates live in `templates/` (`concept.md`, `explanation.md`, `how-to.md`, `reference.md`) and are referenced from the how-to guide; a separate `how-to/build-docs-site.md` documents the MkDocs workflow. The module contains no code beyond the hook script — it is pure content plus a small MkDocs plugin entry point.
