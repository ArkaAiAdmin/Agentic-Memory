Three sibling sub-trees with no shared package boundary:
- `examples/` — self-contained demo scripts (`agent_memory.py`, `langchain_agent.py`, `crewai_crew.py`, `basic_save_search.py`, `streaming_ingest.py`) that import `agentic_memory` (and optional extras like `[langchain]`) to exercise public APIs; each is a `__main__` entry point using `argparse` or env vars and writes to a temp or user-scoped SQLite DB.
- `scripts/` — one-shot / CI-facing Python tools. A small shared helper `_docgen_markers.py` defines the `<!-- AUTO-GEN-START -->` / `<!-- AUTO-GEN-END -->` marker protocol used by every doc generator (`gen_config_doc.py`, `gen_schema_doc.py`, `gen_mcp_tools_doc.py`, `gen_readme_badges.py`, `generate_architecture_md.py`, `verify_doc_meta.py`, `check_update_docs.py`, `doc_drift_check.py`, `tool_drift_check.py`, `cron_wirings_check.py`, `schema_version_check.py`). Other scripts are independent CLI utilities: AST-based config/doc generators, schema/backfill helpers (`backfill_fingerprints.py`, `backfill_colbert_splade.py`), perf regression check, and `worker_memory_guard.py` which watches `background_worker.py` RSS/footprint via `/proc` + `ps` + macOS `vmmap` and SIGTERMs it on breach.
- `_scripts/` — repo-maintenance tooling (`add_flock_to_crons.py` rewrites cron files to inject `_flock.acquire_lock_or_exit`, `remote.sh`).
Dependency direction is strictly outward: these scripts depend on `agentic_memory` (and its integrations) but nothing in the core package imports them. They resolve the repo root via `Path(__file__).resolve().parent.parent` so they can be invoked from any working directory.
