Each package exposes an `ensure_*_schema` function (`knowledge_graph.kg_schema.ensure_kg_schema`, `fact.fact_schema.ensure_facts_schema`) that must be called before any read/write. Background workers in `background/background_worker.py` orchestrate periodic runs of `kg.graph_analytics.update_betweenness`, `kg.graph_communities.compute_communities`, `kg.contradiction_detector.detect_contradictions`, and `fact.consolidate_facts.consolidate_memory_facts`.
